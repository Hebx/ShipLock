# ShipLock branding

**Product:** ShipLock  
**Tagline:** AI writes. Humans ship.  
**Descriptor:** Verified release control for agent-built pull requests.  
**One-liner:** Autonomous agents buy independent code review via Hedera x402; verified maintainers authorize the exact GitHub commit through World Agent Pass before it can merge.

## Design language
Midnight navy `#0B1020` background; violet `#7B3FFF` primary; approval mint `#22E28F`; blue `#3B82F6` informational; amber `#FF8A3D` caution. Use high-contrast accessible text, clean spacing, rounded cards, status steps, exact Git SHAs in monospace, and visible "Verified on testnet" vs "Simulated" evidence tags.

Logo concept: a locked container/ship carrying code, with the release authorization represented by the unlocked/checked merge gate. The generated brand board is a **concept visual**, not UI code; never copy illustrative demo PR numbers, test avatars, or success claims into the live app.

`shiplock_brand_board.png` is the canonical creative direction. `app-icon-concept.png` is a cropped illustrative icon for the first prototype; re-create a crisp vector icon before polished production distribution.

**Brand availability:** The name ShipLock may also be used by other companies; verify domain and trademark before commercial launch. No availability guarantee is made here.

## Usable assets
- `shiplock-mark.svg`: scalable, code-friendly version of the brand mark; suitable for a frontend navbar, favicon source, and loading state.
- `app-icon-concept.png`: image-generated reference crop; use for visual direction, not as an exact vector master.
- `shiplock_brand_board.png`: full inspiration board with illustrative UI. Its depicted approval/results are fictional, not demo evidence.
