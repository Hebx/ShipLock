# Milestone proof artifacts

Each milestone should have an `M0.md`, `M1.md`, ... containing scrubbed commands, assertion outputs and real links. Do not add private keys, cookies, full OIDC tokens, unsigned bank/identity data, raw copyrighted source code or sensitive request bodies to the repository.

Proof status types: **live chain**, **validated World test auth**, **local integration**, **mock fixture**, or **not executed**. Do not mislabel them.
