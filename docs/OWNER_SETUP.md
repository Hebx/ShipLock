# Human maintainer checklist — only the inputs you must supply

1. Create an empty public GitHub repo `Hebx/ShipLock` (or on Glorian-Labs). Don't add a GitHub autogenerated README if uploading this starter's README; otherwise resolve duplicate README manually.
2. Clone and commit this starter. Create a **separate disposable demo target** `Hebx/shiplock-demo-target` for actual merge tests. Install a least-privilege GitHub App or fine-grained PAT restricted to the target repo, not the entire GitHub account.
3. Choose two *distinct* funded Hedera testnet accounts from Hedron: **A = agent payer (ECDSA key accessible); B = audit service merchant/payTo**. Use third account C for optional HCS operator. An existing HBAR-only testnet account is enough; HTS association not needed for the first HBAR x402 test. Do not assume ED25519 will work with the current reference `createClientHederaSigner`; verify key type. Payee does not need a private key merely to receive.
4. Store `HEDERA_AGENT_PRIVATE_KEY` only in local `.env.local` / trusted secret store. Never share it with chat, GitHub or screenshots. Populate IDs locally; only public account IDs may be shared in planning. New ECDSA account only if none of your funded accounts fits or keys were exposed.
5. Check your chosen testnet facilitator's `/supported` (testnet host, HBAR exact, fee payer) at runtime. Hosted facilitator means no fourth personal account is needed. Testnet URLs can change.
6. Register official **World ID Agent Pass** client in `https://auth.world.org/portal`, set HTTPS redirect URI, and store client ID and secret (when required) privately. World authentication is not merge approval; explicit application confirmation is mandatory.
7. If using an LLM summary, supply its API key separately. Deterministic scanner must work without it.
8. For deployment, use persistent DB, protected HTTPS URL, proper GitHub OAuth/App permissions, and World callback. Keep the integration status honest.

**Evidence you should ask the agents for:** actual Hedera transaction HashScan link, full reviewed SHA, verified World callback (without sensitive token), passed and rejected GitHub merge tests, current branch commits, exact commands, and redacted screenshots.
